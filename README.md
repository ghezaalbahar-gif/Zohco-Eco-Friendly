# 🌱 Zohco — Eco-Friendly Website

A modern, responsive eco-friendly website focused on sustainability, green technology, environmental solutions, and sustainable digital design.

🔗 **Live Website:** https://ghezaalbahar-gif.github.io/Zohco-Eco-Friendly/

## 📖 About the Project

**Zohco Eco-Friendly** is a sustainability-focused website designed to showcase environmentally conscious solutions through a modern and clean interface.

The website highlights sustainable technology, renewable energy, environmental conservation, eco-friendly services, and sustainable business practices.

## ✨ Features

* 🌱 Eco-friendly and modern design
* 📱 Responsive layout for different screen sizes
* 🏠 Hero section with sustainability-focused messaging
* 🌍 Environmental values and sustainability sections
* ♻️ Sustainable services showcase
* 💨 Wind and renewable-energy themed content
* ☀️ Eco-friendly e-commerce and green SEO sections
* 📊 Statistics and impact section
* 💬 Client testimonials
* 📰 Sustainability blog/articles section
* 📧 Newsletter subscription section
* 📞 Contact and company information
* 🔗 Social media links

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layout, animations, and responsiveness
* **JavaScript** — Interactive functionality
* **GitHub Pages** — Deployment and hosting

The design uses a clean, nature-inspired visual style with environmental imagery and modern typography. The content is organized into sections such as **Our Values, Sustainable Services, About, Statistics, Testimonials, Blogs, and Contact**.
